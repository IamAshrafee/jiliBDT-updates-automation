# Operator Checklist

## Daily

- Backend and database healthy
- Google connected and recent successful Sheet fetch visible
- Telegram account and bot connected
- Scheduler running; Bangladesh server time looks correct
- Disk healthy and a recent backup exists

## Before the first real send

- Correct spreadsheet, worksheet, date, and update slot
- Correct safe/production destination and forum topic
- Missing, complete, and day-off callers reviewed
- Reminder targets/text reviewed
- Final PNG, caption, source hash, and artifact hash reviewed
- Automation and Telegram switches intentionally enabled

## If anything looks wrong

Pause automation, disable Telegram sending, preserve the run/history, and follow [recovery.md](recovery.md).
